# Framework and Coding Rules

- Framework: Angular `latest` with standalone APIs and signals.
- Prefer self-documenting code and expressive naming.
- Do not add comments unless strictly necessary.
- Break code into focused components/services when it improves clarity.
- Follow functional SOLID principles where practical.
- When the user says `goodnight`, update `SESSION_RESUME.md` by appending a new timestamped session entry using the existing session format.
- For each `goodnight` update include: summary, completed work, exact user run commands for next session, codex next steps, and blockers.
- Keep `SESSION_RESUME.md` entries ordered chronologically (oldest to newest).
